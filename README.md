# Jo Pirat Forum

Небольшой форум на Django для общения и выкладки своих проектов —
вдохновлён классическими phpBB-форумами (категории, темы, ответы).

## Возможности

- Категории → темы → сообщения
- Регистрация и вход
- Создание тем с необязательной ссылкой на проект (GitHub и т.п.)
- Ответы в темах
- Админка Django для модерации

## Запуск локально

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_forum   # создаёт стартовые категории и пользователя admin/admin
python manage.py runserver
```

Форум будет доступен на http://127.0.0.1:8000/

## Стек

- Python / Django
- SQLite (по умолчанию)
- Ванильный HTML/CSS без фронтенд-фреймворков

## Планы

- Личные сообщения
- Аватары и профили пользователей
- Разметка Markdown в сообщениях
- Поиск по форуму
